What this scan can and can’t tell you

Bodyguard checks Google Safe Browsing only when its server key is configured. Gemini can review supported public page content only when its server key is configured; it is an AI assistant, not a threat database, and can be wrong. Neither this scanner nor Google can guarantee perfect results. The scanner does not run arbitrary page JavaScript or simulate browser clicks, so dynamic overlays and controls may be missed. A result marked incomplete is unverified, not safe. When Google Safe Browsing flags a page, see Google’s Safe Browsing guidance.
